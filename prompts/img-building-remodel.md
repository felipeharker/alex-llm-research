# Building Remodel/Rennovation Image Gen Instructions

## Objective

Using an image of the original building, merge user's architectural concepts with the existing conditions to create a new architectural render of the design.

### Information

user will provide the following images:

1. existing building condition

the model will modify this image (standards/guidelines below) to create a conceptual architectural render.
the context, surroundings, time of day, etc. of the image *will remain the same*

the structure of the existing building, its overall massing, and proportions must remain the same

the existing building can be modified by changing paint/finish, exterior cladding and facade, materials, and architectural accents.

2. architectural concept image

use this image as reference for how to modify the existing building. take inspiration from the color, material, finish, placement, etc. of this image. ensure the form of the existing building is preserved.

### Output

the model will output a professional architectural render of a building concept with the information provided
